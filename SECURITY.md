# Security policy

`poincare-memory` runs locally, makes no network calls by itself, and stores data in files you choose. If you find a vulnerability (for example in the HTML inspector, which embeds user text), email dhruvmojila098@gmail.com with details. You will get an acknowledgement within a week and a fix or mitigation plan as soon as the issue is confirmed. Please do not open a public issue for security reports.
